# Zebra DS3678-XR handheld scanner (TRP-T16)

The receiving workstation uses a cordless Zebra DS3678-XR with its Bluetooth cradle. The cradle is
plugged into the Windows PC by USB and acts as a **USB keyboard**: each trigger pull types the
label's data followed by **Enter** into whichever field has focus. Trapezoid needs no driver and
no browser extension.

Every Trapezoid label (TRP-T14) carries the storage unit ID twice, as Code 128 and as QR, and both
encode exactly `PREFIX-YYYY-NNNNNN` (for example `BKT-2026-000014`). Either symbol opens the same
storage unit.

## Where it is used

| Screen                                            | What a scan does                                                             |
| ------------------------------------------------- | ---------------------------------------------------------------------------- |
| **Sample Storage → Scan labels**                  | Looks the label up and shows that storage unit; the next scan replaces it.   |
| **Receive samples → Labels step → Verify labels** | Checks each freshly printed label belongs to one of the units just received. |

Scanning only reads. It never moves, disposes or changes a storage unit (moves by scanning are
TRP-T28).

## Scanner and cradle settings

Set these once per kit, either by scanning the programming bar codes in Zebra's _DS3678 Product
Reference Guide_ or with Zebra **123Scan** on a PC (it writes a configuration you can keep). Record
the kit's serial numbers and the date in the table at the end.

1. **Pair the scanner to its cradle.** Put the scanner in the cradle, or scan the pairing bar code
   printed on the cradle. The scanner beeps when paired.
2. **Host type: USB HID Keyboard** on the cradle (not USB CDC/serial, not SNAPI/IBM).
3. **Symbologies:** **Code 128** and **QR Code** enabled. Others may stay at their defaults; turning
   off ones the office never uses reduces misreads.
4. **Suffix: Enter.** Scan Data Transmission Format = _Data + Suffix 1_, with Suffix 1 = **Enter
   (carriage return)**. Trapezoid treats Enter as the end of a scan; without it nothing happens.
   No prefix.
5. **Keyboard layout** (USB country keyboard type) matching the Windows input language on the
   workstation, normally **US English / North American**. A mismatch types wrong characters
   (`-` is the usual casualty), which shows as "No storage unit found for …".
6. **Batch (buffered) mode: off** ("Normal", do not batch data). If the scanner is out of range it
   must not store scans and type them later: a delayed scan carries no context of where or why it
   was made. Trapezoid never treats a late scan as a move, but it would still open whatever screen
   has focus at that moment.
7. Leave **Caps Lock override** on (if the workstation's Caps Lock is on, the ID still types
   correctly; Trapezoid also upper-cases on the server).

## Using it in Trapezoid

- The scan field takes focus when the screen opens and shows **Ready to scan**. Keep the mouse off
  other parts of the page while scanning.
- If focus moves away (another window, a click elsewhere), the scan panel is covered by **Scanning
  paused — Click here to resume scanning**. A scan made while paused goes nowhere; click the panel
  and scan again.
- The scanner's own beep only means it read a symbol. Trapezoid's result is the large message on
  screen (green **Found …**, red **No storage unit found for …**, amber **Wrong label …**). Tick
  **Play a sound for each result** for a high tone on success and two low tones otherwise.
- The same label twice within 2 seconds counts once ("Already scanned"), so reading the Code 128
  and the QR of one label in quick succession is harmless.
- If Trapezoid can't be reached, the scanned value stays on screen with **Retry**. Nothing is
  queued.
